# Security

This repo holds Business Central per-tenant extensions shared for review. It holds no credentials. The data-load workflows sign in to Business Central with GitHub OIDC through federated credentials, so they keep no client secret.

## Reporting a vulnerability

Please do not post vulnerability details in a public issue.

- Report it privately through GitHub's **Report a vulnerability** button on this repo's **Security** tab (private vulnerability reporting).
- If that is not available, open an issue that says you have a security report, without any details, and the maintainer will arrange a private channel.

Include the affected file or workflow, the steps to reproduce, and the impact you expect.

Issues in Microsoft AL-Go for GitHub itself belong with [microsoft/AL-Go](https://github.com/microsoft/AL-Go/security).
